# FeedBack 0.3.0 Notes

Short answer: FeedBack 0.3.0 is in alpha. The current build is [v0.3.0-alpha.1](https://github.com/got-feedBack/feedBack-desktop/releases/tag/v0.3.0-alpha.1), and a [nightly build](https://github.com/got-feedBack/feedBack-desktop/releases/tag/nightly) is published from the latest code.

## Which Build to Use

| Build | For |
|---|---|
| v0.3.0-alpha.1 | Most testers. |
| Nightly | Trying the newest fixes. Least stable. |

You can switch between them with the update channel in Settings → System → App updates. See [Updating FeedBack](../install/updating.md).

## Before You Start

- Read [Known Limitations](known-limitations.md) for current issues and workarounds.
- Technical release notes are on the [FeedBack Desktop releases page](https://github.com/got-feedBack/feedBack-desktop/releases).
