# Settings Overview

Short answer: Settings is where you manage gameplay, plugins, diagnostics, updates, and app preferences. Audio devices are picked on the separate Audio screen in the desktop app.

## Common Settings Areas

| Tab | Use It For |
|---|---|
| Gameplay | Default arrangement, instrument pathway, A/V sync offset, note highway speed, miss penalty, countdown, left-handed mode. |
| Accessibility | Interface size. |
| Audio | Live guitar tone source, Demucs server for stem separation. |
| Graphics | Settings added by graphics plugins. |
| Keybinds | Keyboard shortcuts. |
| Progression | Settings added by progression plugins. |
| Mic | Settings added by microphone and note-detection plugins. |
| Plugins | Plugin settings and **Plugin updates**. |
| System | App updates, library folder path, Rescan Library / Full Rescan, backup, diagnostics, About. |

Two things live outside Settings:

- **Audio devices** (desktop app): the Audio screen in the main navigation. Pick the input and output device, then click **Apply Device Settings**.
- **Instrument, strings, and tuning**: the instrument selector in the top bar.

## First Things To Check

1. Audio input, on the Audio screen.
2. Instrument and tuning, in the top bar.
3. Calibration.
4. Plugin status, in Settings → Plugins.
5. Diagnostics, in Settings → System.

## Troubleshooting From Settings

- If tuning or scoring fails, check the Audio screen first.
- If a plugin button is missing, check Settings → Plugins.
- If a song is missing, check the library folder path in Settings → System, then click Rescan Library.
- If reporting a bug, export diagnostics after reproducing the issue.
